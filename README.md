# MyTasks

Android-приложение для управления задачами на русском языке. Задачи делятся по
категориям Work / Home и размеру (Daily / Medium / Large), имеют статус
(Started, Waiting, Paused, Stopped) и дедлайн с напоминанием.

Ключевые особенности:

- **Создание и поиск задач через нейросеть** — голосом или текстом через
  AI-провайдера (ProxyAPI, OpenAI-совместимые модели). Запрос «купить молоко
  завтра в 18» превращается в задачу с дедлайном.
- **Синхронизация с сервером** — задачи хранятся и на устройстве, и на
  собственном бэкенде ([MyTasksBackend](../MyTasksBackend)). Удаление
  приложения больше не теряет данные: вход в аккаунт — и задачи вернулись.
  Работает офлайн-первым: без сети приложение полноценно, при появлении сети
  изменения уезжают автоматически (last-write-wins по времени правки).

## Возможности

- Списки задач Work / Home, вкладки Daily / Medium / Large
- Голосовой ввод (распознавание русской речи) и текстовый
- AI-создание и AI-поиск задач (вход через собственный бэкенд по умолчанию)
- Синхронизация: восстановление после удаления приложения, несколько
  устройств на одном аккаунте, корректная репликация удалений (tombstones)
- Вход через Google Sign-In (Credential Manager)
- Напоминания в настраиваемое время (AlarmManager, переживают перезагрузку)
- Тёмная/светлая тема Material3
- Понятная обработка отсутствия сети: быстрый отказ и видимое сообщение
  вместо бесконечного индикатора загрузки

## Стек

Kotlin 2.x · Jetpack Compose + Material3 · MVVM (ViewModel + StateFlow) ·
Hilt · Room (v3, схемы в `app/schemas/`) · Retrofit/OkHttp · DataStore ·
Credential Manager + googleid · minSdk 26 / targetSdk 34

## Сборка и запуск

Требуется JDK 21 и Android Studio (Koala или новее).

```bash
./gradlew assembleDebug   # сборка APK
./gradlew installDebug    # установка на подключённое устройство/эмулятор
./gradlew test            # юнит-тесты
```

### local.properties

Перед сборкой создайте `local.properties` (не коммитится) с ключами:

```properties
backend.url=https://myhome.duckdns.org   # адрес бэкенда (или http://10.0.2.2:8080 для эмулятора)
backend.api.key=<секрет X-Api-Key>       # общий ключ приложения и бэкенда
google.serverClientId=<web-client-ID>    # OAuth Web Client из Google Cloud
```

Без этих ключей приложение собирается и работает в direct-режиме (запросы к
AI-провайдеру напрямую, ключ вводится в настройках приложения); вход в аккаунт
и синхронизация при этом недоступны, локальные функции работают полностью.

## Режимы AI-подключения

- **Backend** (по умолчанию) — запросы идут через собственный Go-бэкенд;
  ключ провайдера и промпты остаются на сервере, авторизация LLM-эндпоинтов
  по `X-Api-Key`, синхронизация — по Google ID-токену.
- **Direct** — приложение само обращается к AI-провайдеру; ключ хранится в
  DataStore устройства.

Переключается в настройках приложения («Подключение к нейросети»).

## Синхронизация

- Вход: меню → «Аккаунт» → «Войти» (Google Sign-In). Без входа приложение —
  обычный локальный менеджер задач.
- Каждая правка помечается версией (`updatedAt`) и уходит на сервер
  отложенно (дебаунс), плюс периодическая сверка при запуске и раз в 15 минут.
- Первый вход заливает существующие локальные задачи на сервер (бэкфилл);
  смена аккаунта заменяет локальный кэш данными нового аккаунта.
- Удаления реплицируются как tombstone-записи и не «воскресают» при
  восстановлении.

## Структура

Исходники: `app/src/main/java/com/shkarov/mytasks/` — `screens/` (Compose-экраны),
`viewmodels/`, `repository/` (включая роутинг direct/backend и декоратор
синхронизации), `sync/` (движок синхронизации и маппинг DTO), `network/`
(Retrofit-интерфейсы и DTO), `data_base/` (Room), `settings/` (DataStore),
`worker/` (напоминания). Схемы Room-БД — в `app/schemas/`.
